# Gap Report rules

How the Gap Report is built at Prepare and how it relates to the Tailored CV. Bound by [0003-no-fabricated-cv-content.md](0003-no-fabricated-cv-content.md) and Tailored CV formatting in [0009-tailored-cv-formatting.md](0009-tailored-cv-formatting.md). Edit Summary (Master → Tailored audit only; never JD gaps): [0012-edit-summary-rules.md](0012-edit-summary-rules.md).

**Status:** accepted

## When and inputs

The Gap Report is produced only at **Prepare**, as part of the Preparation Packet. Re-Prepare overwrites it after the existing warning. It is not rebuilt on every Match Assessment refresh.

Inputs: Job Posting, Candidate Snapshot / Master CV, and existing Relevance Evidence. When Hard Constraint failed, also include Hard Constraint failure lines. Do **not** use Preferences to invent capability gaps (desire ≠ gap).

## What becomes a gap item

- Prefer **required / must-have / minimum** JD items and clear core duties.
- Skip pure nice-to-haves by default (or mark them clearly as optional if included).
- Fully evidenced requirements are **omitted** (not gaps).
- Cap about **5–10** items, prioritizing core must-haves that Relevance already flagged as weak or not found.

Status per item:

- **Missing:** no credible Master CV Evidence (“not found”).
- **Partial:** some related Evidence exists but does not fully meet the requirement (conservative adjacency — same spirit as Relevance rubrics; coursework ≠ production).

Each item: Requirement, status, Evidence from the Master CV (or “not found”), and a Suggestion.

## Suggestions

Suggestions are **non-fictional guidance to the user** — what to learn, clarify on the Master CV, or emphasize from real experience. They must not invent employers, dates, metrics, or skills for the Tailored CV to adopt. The tailor must not treat a Suggestion as license to add missing content.

When Hard Constraint failed: include those failures with Suggestion along the lines of “only proceed if you accept this deal-breaker” — do not suggest hiding the constraint.

## Prepare interaction with Tailored CV

One Prepare produces Gap Report, Tailored CV, and Edit Summary in one packet. Conceptually produce the Gap Report first, then tailor: the tailor may emphasize/reorder using known matches but must **not** fill Missing gaps with invented content. Missing items stay visible in the Gap Report.

If there are no missing/partial required gaps, an empty Gap Report or a single “No required gaps identified” note is valid. There is no auto-loop that rewrites the CV until gaps vanish; the user reviews Gap Report and Edit Summary before applying.
