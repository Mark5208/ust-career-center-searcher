# No fabricated CV content

A Tailored CV may reorder, rephrase, emphasize, or omit experience that already exists in the Master CV, and may rewrite an existing summary section — never invent employers, dates, titles, or skills. Unmet requirements stay in the Gap Report as non-fictional suggestions. Each Preparation Packet includes an Edit Summary so the user can audit those edits before applying; inventing bullets would make the tool complicit in false applications.
