# No fabricated CV content

A Tailored CV may reorder, rephrase, emphasize, or omit experience that already exists in the Master CV, and may rewrite an existing summary section — never invent employers, dates, titles, or skills. Unmet requirements stay in the Gap Report as non-fictional suggestions. Each Preparation Packet includes an Edit Summary so the user can audit those edits before applying; inventing bullets would make the tool complicit in false applications. Structure preservation follows the Master CV format in [0007-rendercv-yaml-master-cv.md](0007-rendercv-yaml-master-cv.md) (RenderCV YAML entries, not LaTeX). Formatting rules (reorder priority, pinned section order, omission/rephrase limits): [0009-tailored-cv-formatting.md](0009-tailored-cv-formatting.md). Gap Report / Suggestion limits: [0011-gap-report-rules.md](0011-gap-report-rules.md). Edit Summary disclosure rules: [0012-edit-summary-rules.md](0012-edit-summary-rules.md).
